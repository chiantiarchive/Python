# Day 1


**Must-know**
- A variable is a name for a value. The four basic types: `str`, `int`, `float`, `bool`.
- `input()` always returns text. Convert with `int()` / `float()` before math.
- f-strings: `f'{name} owes {amount:,.2f}'`. The part after the colon formats numbers.
- String cleaners: `.strip()`, `.title()`, `.lower()`, `.replace()`, `.split()`.
- Floats are slightly inexact, so round money with `round(x, 2)`.
