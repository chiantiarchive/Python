# Day 2


**Must-know**
- `if / elif / else`; comparisons `== != > < >= <=`; combine with `and`, `or`, `not`.
- Empty things are falsy: `''`, `0`, `[]`, `{}`, `None`.
- `def name(param, other=default):` defines a function; `return` hands a value back (`print` does not).
- Call with keyword arguments for clarity: `total(hours=10, rate=50)`.


**Self-check**
1. What is the difference between `print` and `return`?
2. What happens if a function has no `return`?
3. Which of these are falsy: `0`, `'0'`, `[]`, `None`?
